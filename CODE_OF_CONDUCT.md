# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback about the work and not the person. Harassment of any kind isn't tolerated.

Report problems privately through GitHub (Security → Report a vulnerability works for this too), or by contacting the maintainer on their GitHub profile.
